# Русская локализация вселенной The Lantern

## Назначение

Русская версия The Lantern — не буквальный перевод английского текста. Это самостоятельная культурная адаптация одной общей вселенной.

Сохраняем:

- сюжетную причинность, таймлайн и раскрытие тайн;
- механические ID, теги улик, условия, триггеры, имена полей YAML;
- роли персонажей, мотивацию, моральные конфликты и порядок подозрений;
- совместимость web-клиента и Telegram-клиента.

Адаптируем:

- имена, фамилии, титулы и формы обращения;
- названия школ, орденов, домов, служб и локаций;
- виды существ и их социальный статус;
- терминологию магии, обрядов и улик;
- ритм, образность и культурные ассоциации прозы;
- интерфейсные подписи и реплики, чтобы они звучали по-русски.

Английский кейс остаётся канонической механической основой. Русский overlay может менять культурную оболочку настолько сильно, насколько это нужно для естественности, но не должен менять механику.

## Культурная рамка

Базовый регистр — условная восточноевропейская имперская готика конца XIX века с русским языком и восточнославянским фольклорным слоем. Это не буквальная Российская империя и не смесь случайных славянских стереотипов.

Не смешивать без причины русские, польские, украинские, балканские и западноевропейские маркеры. Для каждого нового кейса сначала определить регион, социальную среду и исторический оттенок, затем выбирать лексику.

Тон:

- готический, живой, немного старомодный;
- литературный, но не музейный;
- конкретный и чувственный: печь, порог, копоть, воск, шерсть, полынь, железо, снег, дерево;
- без канцелярита и без псевдофольклорной мешанины;
- без прямого копирования современных мемов, детского фэнтези или «народности ради народности».

## Жёсткие границы адаптации

Нельзя менять:

- `case_id`, location ID, witness ID, evidence ID, spell ID;
- значения `culprit`, `key_evidence`, `points_to`, `trigger`, `condition` и другие механические поля;
- порядок раскрытия улик и условия секретов;
- причинную роль персонажа в преступлении;
- пол, функцию или область действия существа без проверки всей сюжетной цепочки.

Можно менять:

- видимое имя и его падежные формы;
- культурное происхождение персонажа;
- название вида существа, если новая природа сохраняет его функцию;
- названия учреждений и мест;
- образность, метафоры, регистр диалогов и детали быта.

## Имена существ: «подвид + имя»

Для славянских существ использовать структуру:

> **название подвида + личное имя**

Подвид описывает фольклорную природу и сферу действия. Личное имя делает персонажа живым. В первом представлении используется полная форма; дальше в прозе допустимо имя или подвид, если это естественно.

### Домовые

Подневольные `bound familiars` Case 001 — не «фамильяры» и не эльфы. В русском кейсе это **приписные домовые**: духи дома, которых род Тернских юридически и магически удерживает при себе.

Рабочая таксономия:

| Подвид | Сфера | Пример |
|---|---|---|
| Жихарь | дом, порог, защита, хозяин | Жихарь Тихон |
| Запечница | очаг, кухня, тепло, лечение | Запечница Марьюшка |
| Дворовик | двор, переходы, наблюдение, доставка | Дворовик Клим |
| Амбарник | склады, припасы, замки, учёт | Амбарник Никанор |
| Подпечник | тайники, тени, скрытые проходы | Подпечник Федька |
| Овинник | жар, сушильни, опасная огненная магия | использовать редко |

Не использовать `леший` для существа, которое живёт в доме или на кухне. Не использовать `банник`, если действие не связано с баней. Не использовать `кикимора` для мужского домового или просто как универсальное слово для нечисти.

### Case 001

- Wisp → **Жихарь Тихон**;
- Pippa → **Запечница Марьюшка**;
- bound familiar → **домовой** / **приписной домовой**;
- bound-familiar magic → **домовая магия**, **узловая вязь**, **хозяйская печать** — выбирать по контексту;
- slavery binding → **приписная вязь** или **хозяйская печать**.

Не повторять полную форму «Жихарь Тихон» в каждой строке. После представления: `Тихон`, `жихарь`, `домовой Тихон`.

## Человеческие имена и социальные слои

Имена должны сообщать происхождение и класс, а не просто выглядеть «русскими».

Рекомендуемые формы Case 001:

| Английский ID | Русское отображение |
|---|---|
| Aldric Vane | профессор Аркадий Вежин |
| Elena Marsh | Елена Лозовская |
| Cassian Thorne | Касьян Тернский |
| Magnus Thorne | Мстислав Тернский |
| Minerva Whitmore | профессор Мирослава Витязева |
| Rowan Ashford | Родион Ясенев |
| Matthew Croft | Матвей Крофт |

Фамилия семьи всегда: **Тернский**, формы: `Тернского`, `Тернскому`, `Тернским`, `Тернские`.

Аристократические титулы не смешивать случайно. Выбрать одну систему для конкретной локализации: `господин Тернский`, `барон Тернский`, `старший господин`. Не оставлять `лорд`, если остальной социальный слой уже восточноевропейский.

Патронимы использовать только в официальных сценах, документах и моменте сильного социального давления. Не превращать каждую реплику в историческую реконструкцию.

## Учреждения и места

Рекомендуемый словарь Case 001:

| Английский | Русская адаптация |
|---|---|
| Blackwood Collegiate | Чернолесская коллегия |
| Blackwood | Чернолесье / Чернолесский |
| Sealed Archive | Опечатанная библиотека |
| Iron Lodge | Железный двор |
| Scarlet Court | Алый двор |
| Crown Bureau of Supernatural Investigations | Тайный приказ; полная форма — Имперская палата тайного ремесла |
| Lantern Order | Орден Светоча |
| Great Hall | Большая палата / парадная трапезная |

`Опечатанная библиотека` предпочтительнее `Запечатанный архив`: игрок сразу понимает, что это библиотека, а не абстрактное хранилище.

`Орден Светоча` предпочтительнее `Орден Светочей`: это название организации, а не буквальный перевод множественного числа.

## Магия и обряды

Переводить не слово к слову, а по действию и ощущению.

- `rite` → **обряд**, не «ритуал» во всех случаях;
- `ward` → **оберег**, **защитная вязь**, **запор** — по физическому контексту;
- `binding` → **связывание**, **узловая вязь**, **оковы** — по степени телесности;
- `focus` → **фокус** допустим как термин мира; в художественном тексте можно пояснить `волшебный фокус` один раз;
- `occult` → **тайное ремесло**, **заповедное искусство**, **тайноведение**;
- `curse` → **проклятие**, **порча**, **проклятая вещь** — не использовать «порчу» для любого заклинания;
- `familiar magic` → **домовая магия**, а не «магия фамильяра».

Названия обрядов должны быть командами, которые игрок реально может написать:

- `Unveil` → **снять покров** / **открыть скрытое**;
- `Sense Presence` → **почувствовать присутствие**;
- `Identify Substance` → **опознать вещество**;
- `Raise the Lamp` → **поднять лампу**;
- `Echo Reading` → **прочитать отзвук**;
- `Mnemonic Delving` → **войти в память** / **заглянуть в память**;
- `Mend` → **починить**.

Для каждого нового обряда добавить: название, естественную командную форму, краткое объяснение, несколько русских фраз-триггеров и тест на распознавание.

## Интерфейс и кнопки

Кнопки должны звучать как действия игрока, а не как перевод API:

- `Casebook` → **Дело** / **Материалы дела**;
- `Evidence` → **Улики**;
- `Witnesses` → **Свидетели**;
- `Move` → **Перейти**;
- `Verdict` → **Решение по делу**;
- `Begin Investigation` → **Приступить к делу**;
- `End Interview` → **Закончить разговор**.

Избегать `досье`, `локации`, `перемещение`, `вердикт`, если в конкретном интерфейсе есть более живой вариант.

## Мэтью / Матвей

В русской версии отображаемое имя — **Матвей Крофт**. Ключевые обращения должны работать во всех клиентах:

- `Матвей, что думаешь?`;
- `Матвей, посмотри на улику`;
- `спроси Матвея о свидетеле`;
- падежные формы `Матвею`, `Матвеем`, `Матвее` также считаются обращением;
- `Мэтью` — legacy-форма для старых сохранений и привычки игрока;
- `Matthew` — английская fallback-форма.

Распознавание должно происходить до отправки обычного действия следователю. Если сообщение начинается с обращения к Матвею, префикс убирается, а остальной текст отправляется в Matthew API.

## Проза и диалоги

- Одиночный перенос строки внутри YAML не должен становиться переносом в UI; loader складывает авторские строки в пробелы.
- Пустая строка означает новый абзац.
- Не сокращать русский текст относительно английского только ради компактности.
- Не добавлять справочные объяснения в реплики, если смысл можно показать образом или действием.
- Домовые должны говорить с индивидуальным синтаксисом, но не превращаться в карикатуру.
- Третье лицо Тихона — часть характера, а не повод повторять имя в каждом предложении.

## Workflow для нового кейса

1. Определить регион, эпоху, социальные классы и фольклорные источники.
2. Составить таблицу терминов и имён до написания прозы.
3. Зафиксировать подвиды существ и их магические домены.
4. Создать `backend/src/case_store/locales/ru/case_NNN.yaml` поверх английского кейса.
5. Сохранить все механические ID и условия без перевода.
6. Обновить Telegram fallback catalog только для display-текста.
7. Добавить alias-ы для имён, которыми игрок может обращаться к персонажам.
8. Проверить склонение имён в каждом интерфейсе и падеже.
9. Пройти кейс на русском от briefing до verdict в web и Telegram.
10. Проверить, что английская версия и механика не изменились.

## Обязательные проверки

```bash
cd backend
uv run ruff check src tests
uv run pytest -q

cd ../frontend
~/.bun/bin/bun run type-check
~/.bun/bin/bun run lint
~/.bun/bin/bun run test -- --run

cd ../telegram
~/.bun/bin/bun run type-check
~/.bun/bin/bun run lint
~/.bun/bin/bun test ./tests
```

Минимальные acceptance criteria:

- русский игрок понимает, кто такие домовые, до первого расследования;
- ни одна кнопка не выглядит машинным переводом;
- имена склоняются естественно;
- `Матвей` вызывает companion flow, а не narrator flow;
- русские описания имеют ту же глубину, что английские;
- все evidence ID, witness ID, location ID и verdict mechanics совпадают с английским кейсом.

## Обязательные справочные материалы

- [Большая российская энциклопедия: «Домовой»](https://bigenc.ru/c/domovoi-9ab3ce) — базовые функции домового и диалектные названия, включая «жихарь».
- [The East European Journal of American Studies: “The Domovoi in Russian Folklore”](https://ojs.library.ubc.ca/index.php/EJAS/article/view/199552) — академический контекст роли домового как духа дома и отношений с хозяевами.

Справочники нужны для проверки образа и терминов. Они не превращают вселенную в историческую реконструкцию: конкретная магия и сюжет остаются авторскими.
